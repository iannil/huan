# 2026-09-09

## 会话：ebook-exporter 导出文件名随语言本地化

- 需求：使用 exporter 插件导出电子书时，中文版文件名用中文名（title），英文版文件名用英文名（subtitle）。
- 现状调研：
  - 文件名生成在 `plugins/ebook-exporter/plugin.go` 的 `outPath()`：`<outRoot>/<format>/<kind>/<dirName>/<base>[-en].<ext>`。
  - `baseName` 目前为 slug（individual）/ `volume-N`（volumes）/ `<kind>-complete`（complete），英文版仅追加 `-en` 后缀。
  - `BookEntry.TitleZH` 来自 `data/books.yaml` 的 `title`，`TitleEN` 来自 `subtitle`（英文书名）。
  - 聚合单元（卷/全集）的 `TitleEN` 在 `expandUnits` 中合成（"Collected Books: Volume 1" 等）。
  - manifest key `manifestKey()` 与 `baseName` 同源，用于增量跳过；修改文件名需决定 manifest key 是否随之变化。
- 澄清结论：纯标题命名；冒号转全角；`-en` 后缀默认去掉、同名冲突时保留；旧 slug 文件自动清理。
- 设计（方案 A）已获用户批准，规格已提交至 `docs/superpowers/specs/2026-09-09-ebook-export-filename-l10n-design.md`；待用户评审后进入 writing-plans。
