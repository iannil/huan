## 修复主题静态资源全站 404（CSS/JS/图片）+ MathJax 路径

- 更新二进制后页面渲染正常，但浏览器所有静态资源(normalize/zozo/highlight/search/jquery/fancybox/MathJax/favicon...) 404。
- 根因：`internal/build/pipeline_write.go` `copyStaticAndFinalize` 只复制磁盘式 `themes/<name>/static` 和项目 `static/`，
  **完全不处理 .so 主题插件的 embed `Assets()`**。`pkg/plugin/theme.go` 声明 `Assets() fs.FS` 但全仓库无消费者。
  zhurongshuo 主题是 .so 插件，assets 嵌在二进制里(`//go:embed assets/*`)，从未写出 → 全 404。
- 修复：pipeline 加 `writeThemePluginAssets()`，遍历 `themeManager.Active().Assets()` 用 `fs.WalkDir`+`writer.WriteBytesPath`
  写到 `output/theme/<name>/`（对齐模板 `/theme/<name>/...` URL）。TDD：`pipeline_write_test.go` 用 `fstest.MapFS` mock。
  验证：输出文件 49→3146/2974，22/24 资源 200，样式恢复。
- 系统对照模板全部 `/theme/zhurongshuo/` 引用 vs 输出：仅 2 MISS。
  其一 `av-min.js(3.0.4)` 是 grep 误报——`comments.html` 里被**注释掉的 CDN 引用**，非真实请求。
  其二 MathJax：文件在**站点 static/js/MathJax**(304K)、build 输出到根 `/js/MathJax/`(200)，但主题模板 `mathjax.html`
  错误引用 `/theme/zhurongshuo/js/MathJax/`(404)。修复：模板前缀改 `/js/MathJax/`（对齐站点 static 归属），
  重编译 `zhurongshuo.so` 部署 `~/.huan` + 同步 `release/plugins/`。dev 验证 200。
- 经验：主题模板改动 → 必须 `go build -buildmode=plugin -o ~/.huan/<name>.so` 重编译并部署，源码改不生效。
  .so 需与主程序同 Go 版本/依赖。发布约定：同步更新 `release/plugins/<name>.so`。
- 全量 `go test ./...` 30 包全绿。
