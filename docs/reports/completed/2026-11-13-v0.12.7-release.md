## 变更摘要

### 修复（本次唯一的实质变更）

`skipProjectStatic` 会静默发布缺样式的英文站：canonify 把页面里的根相对资源（`/css/a.css`）按语言 baseURL 改写成 `/<lang>/css/a.css`，而被跳过的正是这个目录。处置见 `docs/reports/completed/2026-11-13-asset-integrity-gate.md`。

- 删除 `languages.<code>.skipProjectStatic`；共享 `static/` 永远拷进每个语言输出。
- `internal/config/load.go` 在加载期显式拒绝该键并给迁移提示（typed 解码本会静默忽略未知键）。
- 新增两道构建期门禁（`internal/build/asset_gate.go`），默认失败：
  - 页面引用存在性：canonify 观察到的每个「像静态文件」的根相对引用，必须存在于本语言输出；
  - 语言间对照：每个语言输出必须含全部共享 `static/`（尊重 `staticRoot` / `staticExclude`）。
- `HUAN_ASSET_CHECK=off` 可降级为警告；`build.Result` 追加 `MissingAssets` / `MissingStatic` 两个计数字段（仅追加，Go API 兼容）。
- `output.CanonifyOptions` 新增 `OnRewrite` 回调（nil 时零成本、输出字节不变）。
- `--timings` 新增 `asset gates` 阶段。
