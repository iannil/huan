## 变更摘要

### 性能（zhurongshuo 双语站点，`--noCache` 全量干净构建）

同条件 A/B（git HEAD 旧二进制 vs 新二进制，交替 3 轮，load1≈3.4–6.1）：

| 指标 | 改动前 | 改动后 |
| --- | ---: | ---: |
| 中位耗时 | 1.86s | **1.72s（-7.5%）** |
| 产物文件 | 10261 | **8763（-15%）** |

- `languages.<code>.skipProjectStatic`：语言构建不再重复拷贝共享 `static/`，`staticRoot` 映射保留。zhurongshuo 的 `en` 因此少 1498 个重复静态文件，`static copy` 从约 350ms 降到约 2ms。
- `build` 默认 `GOGC=200`（显式 `GOGC` 环境变量优先）：低负载 A/B 从 2.09s 降到约 1.73s，代价峰值 RSS 约 600MB→900MB。
- `replaceRE` / `findRE` 模板函数缓存已编译正则（上限 512 条），消除 search index 模板的重复编译；非法模式仍在首次调用时 panic。
- `CopyStatic` 改为有界 worker 池，并在 darwin 上优先使用 APFS `clonefile`（写时复制），失败回退字节拷贝。
- 双语并行构建（`HUAN_PARALLEL_LANGS=1`）：各语言写独立 staging 后 rename 合并；实测仅 -6%，**默认关闭**。

### 架构与可观测性

- i18n 模板函数改为闭包绑定 bundle（`FuncMapWithI18n`），`Renderer` 在模板克隆时真正重新绑定 FuncMap；`LoadAllTemplates`/`SetActiveTemplate` 加锁。渲染不再依赖包级 `SetI18nBundle`，为后续并行铺路。
- 新增 `cmd/huan/profile.go`：设置 `HUAN_CPUPROFILE=/path/x.pprof` 时采集 CPU profile，未设置零成本。
- 新增 `scripts/bench-io-floor.py`：按真实产物规模测“纯落盘”下界，用于判断构建时间目标是否物理可达。

### 工具与依赖

- `golang.org/x/sys` 由间接依赖提升为直接依赖（darwin `unix.Clonefile`）。
- `huan.example.yaml` 补充 `skipProjectStatic` 注释示例。

## 勘误（2026-11-13）

`languages.<code>.skipProjectStatic` 的前提不成立，已在后续改动中移除：

- 报告把少掉的 1498 个 `en/` 文件称为「重复静态」。对本站不成立：`canonify` 会把页面里的根相对资源（`/css/normalize.css`）按语言 baseURL 改写成 `https://zhurongshuo.com/en/css/normalize.css`，所以 `static/css` 在 `docs/en/` 下**不是重复，是英文页实际引用的目标**。
- 后果：开启该开关会发布缺样式的英文站，且构建期零提示。
- 处置：删除该开关（配置层显式拒绝并给迁移提示），共享 `static/` 永远拷进每个语言输出；新增资产门禁（引用必须存在于本语言输出 + 各语言共享静态集合必须完整），缺失即构建失败。详见 `docs/reports/completed/2026-11-13-asset-integrity-gate.md`。
- 因此本报告中的「-7.5% / 产物 -15%」不再成立；默认行为回到全量拷贝，新增门禁开销约 17ms/语言（≈1%）。
