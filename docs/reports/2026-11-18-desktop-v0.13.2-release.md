## 7. 人工验收反馈修复与 v0.13.3 重打包（21:0x–21:1x）

用户目检 v0.13.2 后反馈两项，根因调查后均为真实缺陷/设计裁决：

**反馈 1：Dock 图标直角**——根因：macOS 不自动给 app 图标加圆角，品牌图稿本身是直角方形。修复（3b13114）：`gen-brand-icons` compose() 对内容层加抗锯齿圆角遮罩（Apple body radius 185.4/824，符号距离 ≈1px 羽化），TDD 两测试先行（角点 alpha≈0/直边与中心 255/弧点半透明）；重生成 app.icns + icon.png，托盘字形逐字节不变，web 品牌资产不动。icon.png 目检确认 squircle 轮廓。

**反馈 2：缺省仍要 token**——根因调查确认非 bug：桌面接线正确（server.go:187 从站点配置解析），祝融说 huan.yaml 无 admin 段，走的是 ADR 0011 设计缺省 true。用户裁决**缺省翻转为关闭**（1d3204a）：`RequireTokenEnabled()` 仅显式 true 开启；L1 防线不变（非回环 bind 在鉴权关闭时拒绝启动，含缺省情况），暴露网络必须显式 `requireToken: true` + token；专属报错文案随翻转修正（不再建议「移除配置」，指引显式开启），显式 true + 空 token 旧报错逐字节不变。文档：ADR 0011 第二次修订 + 中英 README（cf77fc4）。CLI 三态运行时冒烟 3/3（缺省=单行 disabled 提示 / 显式 true=token 行 / 非回环缺省=拒绝启动）。

**v0.13.3 重打包**（a3a4fec）：`mygo build` → release/desktop/v0.13.3/（zip 7.6M / dmg 5.8M / SHA256SUMS 2/2 OK / README）；bundle AppIcon.icns 与新资产 SHA256 双侧一致（1294469c…）。
