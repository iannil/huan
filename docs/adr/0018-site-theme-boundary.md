# ADR 0018：站点主题与通用生成器分离

- 日期：2026-10-27
- 状态：已实施并通过本地验收；未发布
- 部分取代：ADR 0017 中“Go 主题函数进入内核”和修订提示构建注入的决定

## 背景

ADR 0017 将主题模板与资源移到消费站点，却将其 Go helpers 提升到核心。其结果是核心仍认识 guide fence、站点导读图表白名单、出版修订提示及固定中文阅读时间文案。电子书插件还默认输出同一站点的品牌、域名和封面标记，CSV 导出默认文件名包含该站点名。这些均使通用生成器与单个消费站点绑定。

## 决定

1. 站点主题的唯一归属是消费站点仓库，包括模板、样式、脚本、图表类型、文案、品牌和封面标记。本站继续使用 layouts/、static/、data/；static/theme/zhurongshuo/ 是既有 URL 对应目录，不是另一个主题副本。
2. 删除核心 ThemeFuncMap、funcs_theme.go 和专属修订提示全局配置及构建注入。导读提取、schema 校验与提示过滤在站点 partial/data 中完成。
3. 核心可提供小型通用模板原语：parseYAML、errorf、textWidth/textWrap/textTruncate。文本宽度是字体无关近似（宽字符1em，其余0.55em），不是字体真实测量；它不认识 SVG 图表、书籍、站点名称、语言文案或导读类型。
4. 出版物身份、封面品牌资源和站内链接基址显式由消费站点传入电子书插件，无配置时使用中性行为，不回退任何特定站点。出版配置与资源改变必须使导出缓存失效。
5. CSV 导出提供中性文件名前缀及显式输出参数，消费站点如需旧归档命名由自身脚本传入。
6. 保留通用主题加载/插件机制、管理后台、LiveReload、Markdown数学解析和通用导出能力。历史文档与明确的回归fixture不属于运行时主题依赖，不进行字符串驱动的批量删除。

## 验收

- 核心不再注册八个旧主题专属函数，不存在 publicationRevisionNotice 全局注入。
- 通用函数在无本站模板的测试中独立可用；错误通过模板执行返回。
- 消费站点双语完整构建通过，导读SVG、提示文案和公式与迁移前基线对比。
- 其他出版身份和缺省身份测试不带出本站品牌，导出模块独立测试通过。
- 现有版本变更、发布进度与用户未提交内容不被覆盖。该决定不构成提交、发布或部署授权。
